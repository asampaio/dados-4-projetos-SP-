## Domain Model

NOTE: the domain model should:
- include only concepts of the business;
- include entities an their attributes;
- all entities sould have an identity attribute from the business domain;
- "complex" attributes should be modeled as classes ("value objects");
- include direction in the associations;
- include business meaninfull names for associations;
- include multiplicities in the associations;
- include enumerates if necessary;
- you may also include meaninfull methods realated to the business.
